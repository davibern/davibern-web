## 🚀 Instalación y Uso

### Requisitos Previos

- Un navegador web moderno
- (Opcional) Un servidor web local para desarrollo

### Instalación Local

1. **Clona el repositorio**:
   ```bash
   git clone https://github.com/davibern/davibern-web.git
   cd davibern-web
   ```

2. **Abre el proyecto**:
   - Opción 1: Abre `index.html` directamente en tu navegador
   - Opción 2: Usa un servidor local (recomendado):
     ```bash
     # Con Python 3
     python -m http.server 8000
     
     # Con Node.js (http-server)
     npx http-server
     ```

3. **Accede al sitio**:
   - Abre tu navegador en `http://localhost:8000`

## 🎨 Personalización

### Colores y Tema

Los colores principales se definen mediante variables CSS en `css/style.css`:

```css
:root {
    --bg-primary: #0a0a0f;
    --bg-secondary: #151520;
    --accent: #6366f1;
    --text-primary: #e8e8f0;
    /* ... más variables */
}
```

### Contenido

- **Proyectos**: Edita la sección `#proyectos` en `index.html`
- **Sobre Mí**: Modifica la sección `#sobre-mi` en `index.html`
- **Contacto**: Actualiza los enlaces sociales en la sección `#contacto`

### Estilos

Todos los estilos están centralizados en `css/style.css` y organizados por secciones:
- Variables globales
- Estilos base
- Navegación
- Hero section
- Proyectos
- Sobre mí
- Footer
- Responsive design

1. Asegúrate de que el archivo `CNAME` contenga tu dominio personalizado
2. Configura GitHub Pages en la configuración del repositorio
3. El sitio se desplegará automáticamente en cada push a la rama principal
